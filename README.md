# NOIR — сборка с NovaUI-дизайном (Loader + 3 части + Combined)

Готово: рабочие части, которые грузятся без FAILED, теперь **с новым дизайном NovaUI**
и **аккуратной группировкой функций по вкладкам**.

## Что внутри

| Файл | Что это |
|---|---|
| `Noir_Loader.lua` | Лоадер (2026-11-06) — качает файлы с репо `mellnikovden-sketch/Mm2-plugins` |
| `Noir_Part1.lua` | MM2, часть 1 — ядро + **NovaUI-дизайн меню** (бирюзовые рамки, пружинные анимации, векторные иконки, редактор вида элементов) |
| `Noir_Part2.lua` | MM2, часть 2 — функции (Visuals / movement / меню через `__noirCore`) |

| `Noir_Combined.lua` | Весь MM2 одним файлом (Part1+2+3) — если не хотите GitHub |
| `NovaUI_Builds/Noir_BladeBall.lua` | Blade Ball (NovaUI) |
| `NovaUI_Builds/Noir_MuscleLegends.lua` | Muscle Legends (NovaUI) |

## Что обновлено под новый дизайн (эта сборка)

1. **Меню — полностью NovaUI**: бирюзовый неоновый стиль, пружинные анимации
   (NoirFX), технические уголки-скобки (hudBrackets), векторные иконки вкладок,
   редактор цвета/размера у элементов, градиентные обводки.
2. **Кнопки на экране переведены в новый стиль** (раньше оставались старые
   серебристые): Shoot Murder, Kill Sheriff bind, Grab Gun bind, Invisible bind,
   Aimlock overlay, FOV-круг, Desync — тёмная бирюзовая панель, неоново-бирюзовые
   обводки, голубой градиент «активно», технические уголки.
3. **Исправлена структура меню**: страница функций строилась с ошибкой вложенности —
   теперь все секции корректно раскладываются по колонкам.
4. **Stream Mode**: кнопка разворачивания больше не пропадает; случайное
   переключение на телефоне убрано (только RightShift или кнопка в настройках).
5. **Язык интерфейса**: сохраняется выбранный язык (EN/RU/AR), полный русский
   перевод меню.
6. **Совместимость с лоадером**: ключ защиты `__NoirHubRuntimeLock` — лоадер
   видит работающий хаб и не показывает FAILED.
7. Сохранение настроек (тогглы, слайдеры, позиции окон и кнопок, цвета) — как было,
   папка «Noir UI», автозагрузка при старте.
8. **Исправлен FAILED у лоадера (полностью)**: найдены и устранены три реальных сбоя меню:
   - неопределённые константы области контента (`CONTENT_X/CONTENT_Y`) — падение на nil-арифметике;
   - функция `noirHudCorners` (бирюзовые уголки карточек) вызывалась, но нигде не была определена —
     упала на строке 2358 («attempt to call a nil value»), портирована из Blade Ball-сборки;
   - движок тем (`NOIR_THEMES`, `__NoirFindTheme`, `__NoirApplyTheme`, `__noirThemeReg`)
     отсутствовал — страница тем падала, переключение палитр не работало. Движок перенесён
     целиком (12 палитр + живая перекраска интерфейса).
   Дополнительно исправлен вызов несуществующей `insideCoinContainer` в удалении монет (FPS-режим).
9. **Чистая консоль (раунд 2)**:
   - добавлен безопасный TweenService — твины по уже удалённым элементам больше не
     бросают «TweenService:Create failed because Instance is null»;
   - убран информационный спам «[Noir SNPWARE] + …» из консоли (предупреждения об
     ошибках остаются);
   - ошибки «Icon is not a valid member of Frame» и «UpdateLeaderboard» — от самих
     скриптов игры, не от Noir (исправить их нельзя, они не в нашем коде).
10. **Панель GAME EMOTES переведена в NovaUI**: тёмно-циановая палитра вместо
    серо-зелёной, циановые акценты, циановые кольца и градиенты у круглых
    emote-кнопок, циановые ободы у плавающих кнопок (SpeedGlitch, Better-ODH).
11. **Сохранение настроек дополнено** (папка «Noir UI», автозагрузка): тогглы,
    слайдеры, цвета и позиции сохранялись и раньше; теперь также сохраняются и
    восстанавливаются: скорость спама emotes, размер круглых кнопок, список
    привязанных emote-кнопок (с их позициями) — всё возвращается после перезахода.
12. **NOVA CRYSTAL — премиум-редизайн плавающих кнопок** (не перекраска, а полный
    конструктор `noirNovaButton`, один для всех кнопок):
    - стеклянный корпус с вертикальным градиентом (светлая грань сверху -> тёмное основание);
    - световая линия-блик под верхней кромкой (sheen);
    - вращающийся металлический двойной контур (внешний + внутренний, в противофазе);
    - технические уголки-скобки (HUD brackets) у прямоугольных кнопок;
    - ripple-волна от нажатия + пружинное сжатие/отдача (UIScale, Back-out);
    - единый клик-звук у всех плавающих кнопок.
    Применено к: Shoot Murder, Grab Gun, Aimlock, Invisible, Desync.
13. **Оптимизация (функции не тронуты)**:
    - спиннеры градиентов обновляются на 30 FPS вместо каждого кадра (нагрузка вдвое ниже,
      визуально идентично);
    - вращение градиентных контуров: шаг 0.15с + пропуск невидимых кнопок (меньше
      перерисовок GPU);
    - скан оверлеев движком тем: каждые 2.5с вместо 1с (перекраска при смене темы
      всё равно мгновенная);
    - убраны дублирующиеся градиенты/обводки у плавающих кнопок — по 4-6 лишних
      Instance на кнопку больше не создаётся;
    - то же самое применено к Blade Ball и Muscle Legends сборкам.
14. **Blade Ball: функции разложены по вкладкам** — раньше все модули
    (Ping Spoofer, Player Follow, Hit Sounds, Ability Exploit, Semi Immortality,
    Pull Detection, Orbit Ball и т.д.) сваливались в одну вкладку с префиксом
    «MAIN •». Теперь каждый модуль получает свою категорию: Parry / Main /
    Visuals / World / Misc, в сайдбаре добавлены кнопки World и Misc.
    ВНИМАНИЕ: если в игре у Blade Ball видно только 3 кнопки (Home / Main / Misc) —
    значит на GitHub всё ещё лежит СТАРЫЙ файл: залейте новый
    `Noir_BladeBall.lua` в репозиторий CFG_PM2 (см. «Как запускать»).
    Новый файл легко узнать по сайдбару: 7 кнопок вместо 3.
15. **Blade Ball: Auto Parry ускорен и оптимизирован** (логика не менялась):
    - пинг теперь читается из игры раз в 0.2с (кэш), а не на каждый мяч каждый
      кадр — заметно меньше нагрузки на слабых устройствах;
    - getgenv()-флаги читаются один раз за кадр, а не 3+ раза на каждый мяч;
    - убрано аллоцирование новой таблицы мячей каждый кадр и дублирующее чтение
      атрибута target;
    - ГЛАВНОЕ: исправлен порог дистанции парри. Раньше формула
      clamp(ping/10/10, 5, 40) практически всегда давала 5 стадов даже при
      пинге 300-400мс — парри срабатывал ПОЗДНО и мяч успевал попасть. Теперь
      clamp(ping/10, 5, 40): при пинге 200мс парри бьёт на ~20 стадов раньше,
      при 300-400мс — на 30-40 стадов раньше, при пинге до 50мс поведение
      прежнее. Это соответствует заявленной адаптации движка «под пинг до 400мс».

19. **MM2: исправлен «skins database decode failed» на Delta.** На Delta
    `HttpService:Base64Decode` падает на большой базе скинов (560 КБ base64),
    из-за чего движок ставился с ПУСТОЙ базой — скины не появлялись вообще.
    Теперь весь конвейер не зависит от исполнителя:
    - в прелюдию добавлена чисто-Lua реализация base64/JSON-декодера,
      JSON-энкодера и GenerateGUID-фолбэка (проверена на реальной базе:
      383 скина / 3135 полей — побайтовое совпадение с эталоном);
    - `context.http` — это прокси SafeHttp: сначала честный HttpService,
      при любой ошибке — фолбэк на чистую Lua-реализацию;
    - `take("skins_db")` валидирует результат (длина + первый символ `{`);
    - пустая база больше не проходит молча: `WeaponSkins.load` вызывает error,
      а не пустой каталог (диагностика — в `__NoirSkinsDiag`, консоль молчит).
    Скорость фолбэка: декод базы ~0.1–0.2с один раз при загрузке.

20. **MM2: исправлено «скин не ставится» + чистая консоль.**

      запуске тоггл заранее прописывается включённым в autosave (если юзер
      сам его выключал — выбор сохраняется), тапы по скинам работают сразу.
    - Тихие отказы больше не теряются (диагностика в `__NoirSkinsDiag`): вкладка
      Changer не собралась (какой элемент UI не найден), тап по скину

    - Консоль чистая: удалены белые print-строки «[Noir SpeedGlitch] source
      executing / loaded», «[Inventory Unlimiter V5] Loaded», «[Noir Skins]
      ... installed», «[Noir Auto]».

## Группировка функций (аккуратное расположение, без свалки)

**MM2** — каждая секция помечена префиксом категории:

| Категория | Что внутри |
|---|---|
| `MAIN •` | Invisible, Desync, Universal, Self Mods, Server |
| `AIM •` | Aimlock (+ бинды) |
| `WORLD •` | Gun / Silent Aim, Knife & Pistol prediction |
| `VISUAL •`, `MISC •`, `TROLL •`, `MAP •`, `FARM •` | ESP, FPS, курсор, Emotes, Vote Duper/Controls, Fling, Auto и т.д. |
| `SKINS • WEAPON SKINCHANGER` | Weapon Skin Changer, Knife On Belt, Reset To Real, Type, Rarity, Search, каталог скинов (Part 3) |

Lists / Tuning / Binds / Keys — всё распределено по своим страницам, а не вразброс.

**Blade Ball** — функции разложены по 5 вкладкам (в сайдбаре 7 кнопок:
Home, Parry, Main, Visuals, World, Misc, Settings), а не одной кучей:

| Вкладка | Что внутри |
|---|---|
| **Parry** | AUTO PARRY, DETECTION (Singularity, Pull), SPAM / TRIGGER, Auto Play |
| **Main** | Infinite Jump, Fly, Player Follow, Character Speed, Ability Exploit, Semi Immortality, Look at Ball, Orbit Ball |
| **Visuals** | Skin Changer, Screen Buttons, Status, FPS & Ping, Ball Trail, FOV, Player Cosmetics, Ball Stats, Visualiser, Ability ESP |
| **World** | Filter (атмосфера), Color Correction, Lighting, Sky Color Override |
| **Misc** | Unlock All, FPS Booster, Low Graphics, Auto Rewards, No Render, Ping Spoofer, Name Spoof, Hit Sounds, Sound Controller, Custom Announcer |


**Muscle Legends** — фиксированная раскладка:
- страница **Training**: секции `TRAIN • …`
- страница **Combat**: секции `COMBAT • …`
- страница **Misc**: остальное — без fallback-свалки на одной странице.

## Как запускать

**Рабочий репозиторий (с 2026-11-09): https://github.com/mellnikovden-sketch/Mm2-plugins**

Старые репо `mellnikovden968-web/Gga` и `mellnikovden968-web/CFG_PM2` больше
НЕ используются — аккаунт `mellnikovden968-web` скрыт от мира, raw-ссылки с него
давали 404 (из-за этого лоадер молча грузил старую копию скрипта с 3 вкладками).

**MM2 (по частям — основной способ):**
1. Залейте `Noir_Part1.lua`, `Noir_Part2.lua`, `Noir_Part3.lua` в репозиторий GitHub
   `mellnikovden-sketch/Mm2-plugins`, ветка `main`, имена файлов менять нельзя:
   `Noir_Part1.lua`, `Noir_Part2.lua`, `Noir_Part3.lua`.
2. Запустите `Noir_Loader.lua` через executor.

**Blade Ball / Muscle Legends:**
1. Залейте `NovaUI_Builds/Noir_BladeBall.lua` и `NovaUI_Builds/Noir_MuscleLegends.lua`
   в репозиторий `mellnikovden-sketch/Mm2-plugins`, ветка `main`, под именами
   `Noir_BladeBall.lua` и `Noir_MuscleLegends.lua`.
2. Лоадер сам определит игру и загрузит нужный файл.

**Без GitHub:** выполните `Noir_Combined.lua` напрямую в executor — весь MM2 одним файлом.
